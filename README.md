## 🧠 My Learning Method

For every important concept, I aim to:

1. Understand the fundamental idea.
2. Explain it in my own words.
3. Implement it through code or a practical experiment.
4. Document common mistakes and useful insights.
5. Revisit it using spaced repetition.
6. Apply it to a problem or project.

## 🔄 Revision Strategy

I use a simple revision cycle:

- Day 1: Learn and practise.
- Day 2: Recall the concept without looking at my notes.
- Day 7: Solve a related problem or explain the concept again.
- Day 14: Review difficult parts and common mistakes.
- Day 30: Test whether I can still apply the concept independently.

These are target intervals, not rigid deadlines. Difficult concepts receive additional revision.

## 📈 Progress Philosophy

I value understanding over memorization, practical implementation over passive consumption, and consistent improvement over chasing every new trend.

This repository is a record of what I learn, what I build, what I struggle with, and how I improve.

**Learn → Build → Document → Revise → Repeat.**
